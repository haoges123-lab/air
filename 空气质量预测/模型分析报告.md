# 模型构建问题分析报告

## 1. 核心问题分析

### 1.1 省份嵌入未实现
**问题描述**：
- 模型接收了 `province_ids` 参数，但在 `forward` 方法中完全没有使用
- 训练过程中传递了省份ID，但模型没有利用这些信息
- 不同省份的空气质量模式存在差异，模型无法捕捉这些差异

**代码位置**：`省份空气质量模型.py:33-37`
```python
def forward(self, province_ids, seq_data):
    _, (hidden, _) = self.lstm(seq_data)
    last_hidden = torch.cat([hidden[-2], hidden[-1]], dim=-1)
    prediction = self.fc(last_hidden)
    return prediction
```

### 1.2 输入维度定义不一致
**问题描述**：
- 数据集实际输入维度为 11（7个空气质量指标 + 4个时间特征）
- 模型默认 `seq_input_dim=7`，与实际输入维度不匹配
- 虽然训练时传递了正确的 `FEATURE_DIM`，但模型定义存在潜在风险

**代码位置**：
- `数据集.py:13`: `FEATURE_DIM = 7 + 4`
- `省份空气质量模型.py:10`: `seq_input_dim=7`

### 1.3 模型架构局限性
**问题描述**：
- 简单的 BiLSTM + 全连接层架构可能不足以捕捉复杂的空气质量模式
- 没有针对时间序列数据的特殊处理
- 缺少注意力机制或其他高级结构

## 2. 代码优化建议

### 2.1 添加省份嵌入层
**实现建议**：
- 添加省份嵌入层，将省份ID转换为向量表示
- 将省份嵌入与LSTM输出结合，让模型学习省份特定的模式

**代码实现**：
```python
class AirQualityModel(nn.Module):
    def __init__(
        self,
        num_provinces,
        seq_len=30,
        seq_input_dim=11,  # 修正为实际输入维度
        hidden_size=128,
        num_layers=2,
        dropout=0.3,
        embed_dim=32,  # 省份嵌入维度
    ):
        super().__init__()

        # 添加省份嵌入层
        self.province_embed = nn.Embedding(num_provinces, embed_dim)

        self.lstm = nn.LSTM(
            input_size=seq_input_dim,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            bidirectional=True,
            dropout=dropout if num_layers > 1 else 0.0,
        )

        # 调整全连接层输入维度（LSTM输出 + 省份嵌入）
        self.fc = nn.Sequential(
            nn.Linear(hidden_size * 2 + embed_dim, hidden_size),
            nn.ReLU(),
            nn.Dropout(dropout),
            nn.Linear(hidden_size, 7),
        )

    def forward(self, province_ids, seq_data):
        _, (hidden, _) = self.lstm(seq_data)
        last_hidden = torch.cat([hidden[-2], hidden[-1]], dim=-1)
        # 获取省份嵌入并与LSTM输出结合
        province_emb = self.province_embed(province_ids)
        combined = torch.cat([last_hidden, province_emb], dim=-1)
        prediction = self.fc(combined)
        return prediction
```

### 2.3 增强模型架构
**实现建议**：
- 添加注意力机制，让模型关注重要的时间步
- 考虑使用更先进的时间序列模型，如 Transformer
- 增加模型深度或宽度，提高表达能力

**注意力机制示例**：
```python
class Attention(nn.Module):
    def __init__(self, hidden_size):
        super().__init__()
        self.attention = nn.Linear(hidden_size * 2, 1)
        self.softmax = nn.Softmax(dim=1)

    def forward(self, lstm_output):
        weights = self.softmax(self.attention(lstm_output))
        weighted = torch.sum(weights * lstm_output, dim=1)
        return weighted
```
